# 双指针 
设置 快慢指针i和j

只往一个方向前进
一快j 一慢i
区间内维护某个东西

## 最长连续不重复子序列
~~~
区间
    [1 2 2 3 5]
    [2 3 5] 为最长子序列
~~~
设置数组记录元素看元素是否唯一  
- ### 从数组为空时开始只有两种情况
  - 1.新加入元素未出现过加入序列
    > 则序列延伸即可
    > ~~~
    > if(j<n && map[a[j++]]){
    >    j++; map[a[j]]++;length=max(length,j+1-i);
    >}
    > ~~~
  - 2.新加入元素已存在序列
    > 缩短序列直到新加入元素未出现到加入数列
    > ~~~
    > else{
    >     map[a[i]]--;i++;  
    > }
    > ~~~
